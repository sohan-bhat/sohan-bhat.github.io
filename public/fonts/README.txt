NewCM Web fonts
===============

ncm-web-book.woff2, ncm-web-book-italic.woff2, and ncm-web-bold.woff2 are
derived from New Computer Modern, version 8.1.1, by Antonis Tsolomitis
(based on Computer Modern by Donald E. Knuth and Latin Modern by
B. Jackowski and J. M. Nowacki). These three fonts are distributed under the
GUST Font License (see GUST-FONT-LICENSE.txt), which is the LaTeX Project
Public License 1.3c with an additional request to rename derived fonts.

Changes from the original fonts (2026-10-03):

  - Subset to Basic Latin, Latin-1, general punctuation, arrows, and a few
    symbols. All OpenType layout features are kept (kerning, ligatures,
    small caps, old-style figures).
  - Converted from OpenType (.otf) to WOFF2 for the web.
  - Renamed the font family from "NewComputerModern" to "NewCM Web", and
    renamed the files, as the license requests.

Files and their sources:

  ncm-web-book.woff2         NewCM10-Book.otf
  ncm-web-book-italic.woff2  NewCM10-BookItalic.otf
  ncm-web-bold.woff2         NewCM10-Bold.otf

The complete, unmodified fonts are available from CTAN:
https://ctan.org/pkg/newcomputermodern

The original authors do not support these modified files.
